# TikTok Shorts Video Engine 🎬

Automated AI-powered short video generator using **GitHub Actions**.

### Features:
- 🎙️ **Voiceover (TTS):** Microsoft Edge-TTS with deep stoic narration (`id-ID-ArdiNeural`).
- ✍️ **Karaoke Dynamic Subtitles:** Powered by `whisper-timestamped` (dynamic word-by-word bold subtitles).
- 🎵 **Background Music (BGM):** Emotional piano ambient with audio ducking.
- 🎥 **Footage:** HD Vertical (9:16) video clips.
- 📊 **Google Sheets Sync:** Automatically fetches quotes with `status = READY` and updates to `status = DONE`.
